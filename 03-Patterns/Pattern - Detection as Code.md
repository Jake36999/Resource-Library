# Pattern - Detection as Code

## Definition
Security detections are authored as version-controlled text, reviewed through pull requests, tested, and compiled or deployed to the detection engine as an artefact.

## Why It Matters
- Gives the vault a reusable architectural concept for graph traversal.
- Helps compare repositories that solve the same problem in different ways.
