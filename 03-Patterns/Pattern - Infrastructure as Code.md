# Pattern - Infrastructure as Code

## Definition
Declarative provisioning and configuration of infrastructure using code instead of manual setup.

## Why It Matters
- Gives the vault a reusable architectural concept for graph traversal.
- Helps compare repositories that solve the same problem in different ways.
