# Pattern - Reference Architecture

## Definition
An annotated repository that exposes architectural decisions, code structure, and reusable design contracts.

## Why It Matters
- Gives the vault a reusable architectural concept for graph traversal.
- Helps compare repositories that solve the same problem in different ways.
