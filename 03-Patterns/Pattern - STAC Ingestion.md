# Pattern - STAC Ingestion

## Definition
Earth-observation assets are described as linked JSON items in a spatiotemporal catalogue, making imagery archives crawlable and queryable by geometry and date.

## Why It Matters
- Gives the vault a reusable architectural concept for graph traversal.
- Helps compare repositories that solve the same problem in different ways.
