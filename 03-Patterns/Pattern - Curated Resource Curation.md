# Pattern - Curated Resource Curation

## Definition
A repository pattern that aggregates, annotates, and routes users toward other resources rather than implementing a single end-user tool.

## Why It Matters
- Gives the vault a reusable architectural concept for graph traversal.
- Helps compare repositories that solve the same problem in different ways.
