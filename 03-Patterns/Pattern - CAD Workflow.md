# Pattern - CAD Workflow

## Definition
A pipeline from parametric source model through geometry kernel to exchange formats (STEP, STL, DXF) that downstream manufacturing or simulation tools consume.

## Why It Matters
- Gives the vault a reusable architectural concept for graph traversal.
- Helps compare repositories that solve the same problem in different ways.
