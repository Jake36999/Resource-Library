# Pattern - Knowledge Graph Routing

## Definition
A graph structure that routes from top-level indexes to topics, glossary terms, patterns, and resources using typed links.

## Why It Matters
- Gives the vault a reusable architectural concept for graph traversal.
- Helps compare repositories that solve the same problem in different ways.
