# Glossary - Vector Database

## Definition
A store whose primary operation is finding the points nearest to a query point in a high-dimensional space. The distinguishing feature is the approximate nearest-neighbour index; without one, the same job is a brute-force scan, which is correct and often fast enough.

- vector store
