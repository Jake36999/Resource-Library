# Glossary - Semantic Search

## Definition
Retrieval that matches on meaning rather than on shared terms, so a query and a document can match with no words in common. Its complementary weakness is exact tokens — identifiers, codes, rare names — which lexical search handles and it does not.

## Aliases
- meaning-based search
- dense retrieval
