# Glossary - Concrete Syntax Tree

## Definition
A tree representation that retains every character of the original source, including whitespace, comments and punctuation, so the tree can be printed back out byte-identically. It is what a tool needs when it must modify one part of a file and leave the rest untouched.

- CST
- lossless syntax tree
