# Glossary - Ontology

## Definition
A formal statement of what kinds of things exist in a domain and how they may relate, expressive enough to be reasoned over. Distinct from a taxonomy, which arranges terms in a hierarchy, and from a schema, which constrains a representation: an ontology is about the subject, not about the file.
