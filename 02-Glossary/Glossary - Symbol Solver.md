# Glossary - Symbol Solver

## Definition
The component that answers which declaration a given name refers to, given everything else in scope. It is a separate and harder problem from parsing — in [[javaparser - javaparser]] the resolution tests outnumber the parser tests more than two to one — because the answer depends on context a tree does not carry.
