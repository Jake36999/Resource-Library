# Glossary - Embedding

## Definition
A fixed-length numeric representation of an item, produced by a model, positioned so that items with similar meaning sit close together. Which model produced it is part of the data: vectors from two models are not comparable, and changing the model invalidates every stored vector.

- vector representation
- dense vector
