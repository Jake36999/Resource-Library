# Glossary - Column-Level Lineage

## Definition
Lineage recorded per field rather than per dataset: which input columns a derived column was computed from. It is the granularity at which impact analysis becomes useful, because a change to one field rarely affects everything downstream of the table it lives in.

## Aliases
- field-level lineage
- column lineage
