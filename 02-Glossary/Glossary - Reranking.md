# Glossary - Reranking

## Definition
Reordering a small candidate set with a more expensive model than the one that retrieved it. The economics are the whole idea: a model too slow to score a corpus can score fifty candidates, so recall is bought cheaply and precision expensively.

## Aliases
- second-stage ranking
- cross-encoder reranking
