# orsinium-labs - generated-awesomeness

## Bottom Line
A collection of awesome lists produced entirely by machine: a generator queries the GitHub search API, ranks results by stars and sorts them, with the explicit rule that no manual editing occurs at all.

## What It Solves
- Keep a list current without a maintainer curating it by hand.
- Remove the inconsistency and staleness that hand-maintained lists accumulate.
- Make list generation reproducible — regenerate rather than update.

## Architecture & Mechanics
- The `awesome-generator` tool queries the GitHub search API to compile candidates.
- Entries are ranked by star count and sorted alphabetically within categories.
- The stated policy is full auto-generation with no manual editing.
- Contributors generate new lists with the tool and submit those, rather than editing entries.

## What Is Inside
- **45 files, and the generation is the point** — `topics/` (23 lists) and `languages/` (18), each a Markdown list assembled programmatically from GitHub metadata rather than curated by hand.
- **What that buys and costs** — coverage is even and refreshable, but there is no editorial judgement: entries are ranked by signals, not by whether anyone found them useful. Read it as a ranked survey of a topic, not as a recommendation.
- **Nothing executable is checked in.** The generator itself is not in this repository; only its output.
- **Where it is useful here:** as a breadth check when scouting a domain — comparing a hand-curated list against a generated one shows what curation excluded.

## Transferable Capability
**Generate a survey from measurable signals rather than curating it, so coverage is even and refreshable.** The trade is explicit and worth understanding: nothing is omitted through ignorance, and nothing is included because it was useful. Read against a hand-curated list of the same territory, the difference between the two *is* the editorial judgement, made visible.

**Alternative to:** curation, which is selective in ways nobody records. **Applies wherever** breadth matters more than judgement — and as a control: comparing a generated survey against a curated one shows what curation actually decided.
