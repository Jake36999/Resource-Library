# pracdata - awesome-open-source-data-engineering

## Bottom Line
A curated landscape of 200-plus open-source data engineering tools organised into nine layers, from storage systems up through metadata management and ML platforms, aimed specifically at analytics platform building rather than software generally.

## What It Solves
- See the whole data platform stack laid out by layer rather than by popularity.
- Find candidates for a specific layer — metadata, orchestration, storage — without a general search.
- Understand how the layers interconnect in a modern platform.

## Architecture & Mechanics
- Nine categories: storage systems, data lake platform, data integration, processing and computation, workflow management and DataOps, data infrastructure, metadata management, analytics and visualisation, and ML/AI platform.
- Storage alone subdivides into sixteen database types including relational, NoSQL, graph and time-series.
- The scope is explicitly analytics and data engineering rather than software in general.
- An accompanying landscape visualisation shows how the categories relate.

## What Is Inside
- **One file.** `README.md` is the entire repository — no licence, no scripts, no assets.
- **What it contains** — the open-source data engineering landscape organised by layer (ingestion, storage, query engines, orchestration, catalogues, quality, observability), which makes it usable as a category map rather than only as a link list.
- **Nothing is vendored.** Entries decay with their targets, and the compilation carries no grant.
- **Where it is useful here:** as a coverage check when scouting `data_api_big_data` — its layer breakdown names categories the catalogue can test itself against.

## Transferable Capability
**Organise a field by the layer each thing occupies rather than by its name**, so the compilation doubles as a map of the problem space. A reader learns what categories exist — which is often the actual need — before learning what occupies them, and a gap in the map is visible as an empty category.

**Alternative to:** an alphabetical list, which cannot show that a category exists and is unfilled. **Applies wherever** somebody needs to understand the shape of a field before choosing within it — including a catalogue testing its own coverage against an external account of the same territory.
