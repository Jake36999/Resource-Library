# ByteByteGoHq - system-design-101

## Bottom Line
A visual-first reference for system design: each concept — API gateways, CDNs, consistency models, deployment strategies — is explained through a single diagram plus short prose.

## What It Solves
- Convey architectural concepts to mixed audiences faster than prose alone.
- Provide reusable diagram vocabulary for design documents and reviews.
- Give a quick refresher on a specific concept without reading a whole book.

## Architecture & Mechanics
- Content is organised as short concept entries, each anchored by one diagram.
- Diagrams use a consistent visual grammar across topics.
- Sections span protocols, databases, caching, deployment and real-world architectures.
- Note that upstream activity has been quiet since 2025 — treat currency accordingly.

## What Is Inside
- **400 standalone explainer articles** — `data/guides/`, one Markdown file per topic, each built around a diagram: API testing types, network protocols, sessions/tokens/JWT/SSO/OAuth, UML class diagrams, diagram-as-code, and so on. 418 of the repository's 424 files are Markdown.
- **A category index** — `data/categories/` (15 files) grouping the guides.
- **Nothing executable** — one `.ts` file, one workflow, one script. There is no site generator in the repository; the content is the artefact.
- **Where the value is:** the guides are individually addressable and individually readable, so this is a reference to search rather than a book to read. **Its LICENSE grants nothing recognisable**, so lifting the diagrams is legally undetermined.

## Transferable Capability
**Reduce each concept to one picture and one page, and make every page independently addressable.** Constraining an explanation to a single diagram forces a decision about what the concept actually is, and independent addressing means the collection is used by reference rather than read through.

**Alternative to:** a linear document where a concept exists only in context and cannot be cited alone. **Applies wherever** a body of explanation will be consulted rather than read — which is most of them.
